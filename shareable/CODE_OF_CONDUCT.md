# Code of Conduct

## The short version

Be decent. Assume good faith. Argue about the work, not the person.

## Expected behaviour

- Give feedback on ideas, code and decisions — specifically, and with a reason.
- Accept feedback the same way. A rejected pull request is not a verdict on you.
- Respect that contributors work in different languages, time zones and contexts.

## Unacceptable behaviour

- Personal attacks, harassment, or demeaning comments about a person or group.
- Publishing others' private information without permission.
- Sustained disruption of discussions or reviews.

## Enforcement

Report a problem by opening an issue marked `conduct`, or privately to the
repository maintainers. Reports are handled confidentially. Maintainers may
edit, remove or reject contributions, and may block accounts, for behaviour they
judge inappropriate.

This code applies in the repository, its issues and pull requests, and any space
where someone is representing the project.
